# Drift Algorithms

Original research packages sold through the Drift storefront.

| Package | Style |
|---------|--------|
| `dawn_orb/` | Dual-session opening range breakout |
| `steady/` | Volume-confirmed mean reversion |
| `lift/` | Trend continuation / pullback |
| `apex/` | Regime + breakout + risk overlay |

## Run research backtests

```bash
python3 algorithms/run_backtests.py
```

Metrics on the website are produced by this runner on synthetic session data.
They are research illustrations, not live brokerage performance.

## Risk

Trading futures, options, crypto, and leveraged products involves substantial risk of loss.
Only automate with capital you can afford to lose. Past research results do not predict future returns.
